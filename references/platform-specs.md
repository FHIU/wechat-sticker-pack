# 微信表情开放平台 · 参数速查

> 来源：项目内两份执行手册转述 + 2026-11-05 平台实测。**提交前请复核平台现行规范**，本表仅作流程内自检。

## 一、上传参数（本技能 S0 必须逐项确认）

| 项 | 选项 | 说明 |
|---|---|---|
| 上传类型 | 静态表情 / 动态表情 | 同一专辑不可动静混排 |
| 图片格式 | PNG / GIF / APNG / JPG | 静态优先**透明 PNG**；动态用透明 GIF 或 APNG；JPG 不支持透明，仅用于横幅等不透明场景 |
| 总张数 | 8 / 16 / 32 | 平台一般要求 8–24 张，32 张需确认该专辑类型是否允许 |
| 主模板图来源 | 提示词生成 / 参考图垫图 | 垫图只借外观、忽略参考姿势 |
| 文字位置 | 右上角 / 嘴部台词浮框 / 其他 / 自行决定 | 套内必须完全一致 |

## 一·补、填写附加信息（S1，生图之前必须逐项确认）

> 来源：微信表情开放平台「填写附加信息」表单截图。四项均不得默认，确认后写入《附加信息卡》并回灌提示词。

| 字段 | 选项 | 约束 / 落地要求 |
|---|---|---|
| 类型 | 真人拍摄表情 / 截图表情 / **卡通表情·其他** | 单选，决定母图画风；Q 版贴纸选「卡通表情/其他」 |
| 角色／内容 | 下拉选择表情的主角（单一角色 / 角色＋配角 / 无具体主角） | **角色出现在表情的个数不少于表情总个数的 1/3**；16 张需 ≥6 张出现主角 |
| 表情风格 | 选 **1 项或 2 项**：日常、软萌可爱、二次元、长辈风、搞笑、丧/佛系、魔性鬼畜、恶搞、简笔画、赛博朋克、蒸汽波、像素、暗黑、复古 | 最多 2 项；必须体现在母图画风、配色、线条与整套气质 |
| 表情主题 | 万能通用、网络热点、节日、考试/学习、工作/职场、情侣、毕业、刷屏、红包相关、游戏、运动/健身、怼人/斗图、群聊必备、节气、邀约·约起来、励志鼓舞 | **与主题相关的表情个数不少于表情总数的一半**；16 张需 ≥8 张，表情名称清单按此校验 |

**计数校验（提交前必做）**：`含主角张数 ≥ ceil(总数/3)`，`与主题相关张数 ≥ ceil(总数/2)`。
**冲突处理**：若用户选的类型／风格与已生成的母图冲突，重出母图并重新走母图验证关卡，不得带着冲突继续。

## 一·补二、表情名称清单（S5，母图验证通过后、总览排版图之前）

> 用户 21:23 指令新增「整套名称由用户定」；用户 21:33 指令修订（1.3.0）：**名称由技能依据本套主题与风格推荐，先推荐、再由用户逐张决定是否采用**。推荐不强制，是否使用由用户决定。

| 项 | 要求 |
|---|---|
| 推荐依据 | 必须来自已确认的《附加信息卡》：**表情主题 ＋ 表情风格 ＋ 角色／内容**，并说明每条的推荐理由 |
| 推荐效力 | **仅供参考，不自动生效**；未经用户明确采用，不得写进《表情清单》 |
| 询问方式 | 按 `01…N` **一次只问一个编号**「是否采用这个名称」，**共 N 次**（16 张即 16 次）；不批量、不跳号、不默认采用 |
| 用户三选 | 采用 / 我自己起一个（技能不改写） / 换一个推荐（只重问该编号，不新增编号） |
| 条数 | 严格等于总张数（8 / 16 / 32）；N 次征询缺一次都停在询问 |
| 格式 | 每条一个表情名称，建议 ≤4 字、无标点（可直接用作平台逐张「含义词」） |
| 推荐也要计数 | 推荐清单须满足：与主题相关 ≥ 总数一半（16 张 ≥8）、含主角 ≥ 总数 1/3（16 张 ≥6） |
| 技能动作 | N 次全部完成 → 原样编号回显 → 数量校验 → 重复检查 → 与本表 1/3、1/2 计数对表 → 请用户确认清单 |
| 冲突处理 | 计数不达标只提示用户调整，**不自行替换任何一个名称** |
| 阻断 | 任一编号未拍板、或清单未确认 → 不生成总览排版图、不生成任何单张成品 |
| 落地 | 确认后的《表情清单》写进提示词文稿并进入最终交付；总览每格与每张成品严格对应清单该编号，不换词、不调序、不增删；清单变更须退回本关并同步重出总览图 |

**采用记录模板（16 张，逐张填写）**
```
01 推荐＿＿＿＿ → 采用/自定→＿＿＿＿
02 推荐＿＿＿＿ → 采用/自定→＿＿＿＿
… 共 16 行，每行对应一次询问
16 推荐＿＿＿＿ → 采用/自定→＿＿＿＿
```

## 二、表情主图规格

| 项 | 值 |
|---|---|
| 尺寸 | 240 × 240 px |
| 背景 | 透明（RGBA，四角 alpha=0，无白边、无棋盘格、无水印） |
| 体积 | ≤ 500 KB / 张 |
| 构图 | 主体完整入画、精确居中、四边留白、不裁切关键部位、不拉伸变形 |
| 文字 | 清晰可读、不遮挡主体、无溢出/重叠/变形/错字；同套同位置同字号 |
| 内容 | 每张严格对应《表情清单》该编号的表情名称 |
| 数量 | 8 / 16 / 32（按专辑类型） |

## 三、上架素材规格

| 素材 | 尺寸 | 格式 / 体积 | 要求 |
|---|---|---|---|
| 封面 | 240 × 240 | PNG，透明底，≤500KB | 完整角色，**不能只有头部特写**；无文字、无边框、无白描边 |
| 图标 | 50 × 50 | PNG，透明底，≤100KB | **只用头部正面**，识别特征齐全，无身体手臂 |
| 横幅 | 750 × 400 | PNG/JPG，≤500KB | **可含标题文字与品牌 logo**（左上角小徽标最稳）、禁二维码/联系方式；非白底、非透明底，与微信白底区分 |
| 艺术家主页横幅 | 750 × 400 | ≤80KB | 体积上限更严，需单独压一版 |

> **横幅与 logo（2026-11-05 修正）**：此前版本写「横幅禁文字、禁 logo」，实测并非硬约束——官方横幅位就是用来放专辑名与品牌标识的。可放的：专辑名／slogan、工作室纯图形徽标。不可放：二维码、联系方式、第三方平台水印、密集小字（缩到手机端会糊）。构图建议：徽标左上、标题左侧、角色右侧，标题与徽标左边距对齐同一根竖线。

## 四、文字字段字数

| 字段 | 上限 | 备注 |
|---|---|---|
| 名称 | ≤8 汉字 | 无标点、不加空格，5 字内显示最佳；提交前查重 |
| 介绍 | ≤80 汉字 | 连成一段，不换行 |
| 版权 | ≤10 汉字 | 需与艺术家主页名称一致；占位署名必须替换 |
| 含义词 | ≤4 字 / 条 | 逐张单独填，与图上配字是两回事；同套不重复、无标点；可直接取自用户确认的《表情清单》 |

## 五、上传顺序

```
图标 → 封面 → 横幅 → 逐张表情（01…N）→ 名称/介绍/版权 → 逐张含义词 → 提交
```
首次建议先传 8 张验通审核链路，再补到 16 / 32 张。

## 六、平台实测坑（必看）

1. **深色聊天背景**：平台预览为近黑底。透明底上的深色文字会「消失」，必须带浅色描边或浅色底。
2. **缩略图**：验收时必须把成品缩到 64×64 放在近黑底上看一次，只看 240 原图会漏判。
3. **真透明**：图像模型的「透明背景」参数常画出棋盘格 + 右下角水印，不是真 alpha；需白底生成后抠透明。
4. **中文**：不由模型绘制，一律后期系统字体叠加；否则错字、繁体混入、伪字符。
5. **不同专辑**：封面与图标不可沿用上一套。
6. **合规**：第三方素材需结构性差异化并留存各版中文提示词与生成时间作独立创作存证；AI 生成内容按《人工智能生成合成内容标识办法》如实标注；不保证过审。
7. **闭环空洞（最易漏的白块）**：抠透明时若只清「与画布四边连通」的背景，被角色自身围住的白色区域会残留——典型是**耳下珠链与脸颊／肩膀围成的环**、手臂与躯干之间的闭合缝隙。深色聊天底上表现为「链子周围一圈白」，客户会直接看出来。必须补一步闭环空洞检测：不连通四边 + 近白（亮度≥236、饱和度≤14、面积≥120@1024）→ 判为背景透明化；带描边的银珠本身保留。抠完自检：近白不透明残留连通块应≤个位数像素。

## 七、透明底抠图三步（固定口径）

```
① 清四边连通浅色背景（亮度≥226 且饱和度≤30），只清连通域，不清角色内部白（方巾/眼白/高光）
② ★ 清闭环空洞（见上第 7 条）——珠链围成的白、臂与躯干间的闭合缝
③ 自检：四角 alpha=0 / 近白残留≤个位数像素 / 半透明白雾不可见 / 文字区侵入=0
```
白色或浅色主体（银发、白方巾）不要用「整幅按亮度抠」，一定用连通域，否则会把主体抠出洞。
