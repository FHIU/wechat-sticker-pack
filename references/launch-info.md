# 上架文案模板与实例

## 一、字段字数与写法

| 字段 | 上限 | 写法 | 常见错 |
|---|---|---|---|
| 名称 | 8 汉字 | 「角色名 + 主题词」结构，便于搜索命中 | 超过 8 字；带标点；与已上架专辑重名 |
| 介绍 | 80 汉字 | 外观特征 → 性格 → 使用场景 → 一句收尾 | 写成分集剧情；换行；把版权写进来 |
| 版权 | 10 汉字 | 个人名或工作室名 | 塞年份、网址、邮箱 |
| 含义词 | 4 字 / 条，无标点 | 直接用图上短句，去掉问号感叹号 | 带「？」，个别情况被判不合规 |

计数按字符算，标点也占位，写完用脚本或手工数一遍。

## 二、名称公式

```
[角色名 3–4 字] + [主题词 2–4 字]
```

示例：
- 角色「银灰先生」+ 主题「怼人/斗图」→ 银灰先生怼人日常（8 字）
- 角色「小笼包」+ 主题「万能通用」→ 小笼包打工日常（7 字）
- 角色「阿狸」+ 主题「情侣」→ 阿狸恋爱日常（7 字）

搜索考虑：角色名放在最前，主题词用用户会搜的口语词（怼人、打工、摸鱼），不要用抽象词（陪伴、治愈）。

## 三、介绍模板（70–78 字最稳）

```
[外观 8–14 字]，[性格 10–16 字]。[场景痛点 8–12 字]：[三条功能 12–18 字]，[一句收尾 6–10 字]。
```

实例（银灰先生 · 72 字）：

> 黑西装、银饰、金丝眼镜，银灰先生一副冷脸，嘴上从不饶人，偏偏句句客气到挑不出错。16 个动态表情专治群聊冷场：回怼、摆烂、体面告辞，发出去就赢。

拆解：外观 11 字｜性格 20 字｜场景 10 字｜功能 19 字｜收尾 6 字。

反面示例（别这么写）：
- 「这是我的原创表情包，希望大家喜欢，多多支持」——没有信息量，白占 80 字额度
- 「银灰先生是一名…（背景故事 200 字）」——写不下，且用户不看

## 四、含义词清单

```
09 懂了    10 随便    11 嗨      12 好的
13 想想    14 无语    15 收到    16 回见
```

注意：含义词与图上配字是两回事，可以更短（图上「你行你上」→ 含义词「你上」），但必须语义一致，且全套不重复。

## 五、附加信息选择经验

| 字段 | 选择原则 | 易踩 |
|---|---|---|
| 类型 | Q 版贴纸一律「卡通表情/其他」 | 选了「真人拍摄」，审核会打回 |
| 角色/内容 | 先创建角色再下拉选择；角色图用透明底全身图 | 角色张数 < 总数 1/3 直接不达标 |
| 表情风格 | 只选真正贯穿全套的 1–2 项 | 觉得「赛博朋克」贴就勾，但画风是萌系 → 风格不符 |
| 表情主题 | 单选，选表情文案实际占比最高的那个 | 主题相关的张数不足一半 → 不达标 |
| 下载地区 | 中文梗选「中国大陆」 | 选「全球」不增加曝光，还可能被判内容不适配 |

## 六、完整填写单（可直接照抄结构）

```
名称：<角色名><主题词>            （≤8 字）
介绍：<外观><性格>。<场景>：<功能>，<收尾>。（≤80 字）
版权：<署名>                      （≤10 字）
横幅：横幅_750x400.jpg            （无文字、非白底）
封面：封面_240x240.png            （完整角色、无文字无边框）
图标：图标_50x50.png              （仅头部正面）

类型：卡通表情/其他
角色/内容：<角色名>（需先创建角色并上传角色图）
表情风格：<1–2 项>
表情主题：<1 项>
上架地区：中国大陆（固定）
下载地区：中国大陆

含义词：01…N 逐张，≤4 字无标点
```

## 七、上传顺序

1. 创建/选择角色（上传角色图）
2. 基本信息：名称 → 介绍 → 版权 → 横幅 → 封面 → 图标
3. 附加信息：类型 → 角色 → 风格 → 主题 → 下载地区
4. 逐张上传成品（按 01…N），逐张填含义词
5. 提交审核

首次建议先传 8 张验通审核链路，再补到 16 / 32 张。
