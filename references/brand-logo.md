# 品牌徽标（车标式单标记）

> 用途：给工作室／店铺做一个可复用、可缩到 20px 还不糊的纯图形标志，能压在横幅、封面以外的任何画面上。

## 一、设计口径

| 项 | 规范 |
|---|---|
| 构成 | **单一标记，不带文字**。文字（工作室名）属于另一套字标，不混进标记里 |
| 颜色 | 单色、无渐变、无描边、无投影。只做两版：浅色 `#EDF1F6`（用于深底）、深色 `#14181D`（用于浅底） |
| 形状 | 一个主块 + 一个次要块（如鱼身 + 尾鳍），靠 **负空间挖孔** 制造记忆点（眼孔） |
| 比例 | 主块：次块 ≈ 1.6 : 1；整体外接框长宽比 1.1 : 1 左右，便于方形容器里摆放 |
| 最小尺寸 | 20px 高仍能辨认轮廓。低于 20px 不要用这个标记，改用纯色块 |

## 二、生成

```bash
python3 scripts/mark.py --height 512 --out logo --color EDF1F6 --suffix 浅色
python3 scripts/mark.py --height 512 --out logo --color 14181D --suffix 深色
for h in 256 128 64 32; do
  python3 scripts/mark.py --height $h --out logo --color EDF1F6 --suffix 浅色_$h
done
```

脚本只暴露三处几何常量，换行业只改这三行：

```
BODY = (cx, cy, rx, ry)        主体椭圆
TAIL = [(x,y) ...]             次要形状多边形（尾鳍／叶／角／翼）
EYE  = (cx, cy, r)             负空间圆孔
```

生成的 PNG 是 4 倍超采样后 LANCZOS 缩小，边缘干净、无锯齿硬边。

## 三、矢量版

同一套坐标直接写 SVG，viewBox 用 `0 0 110 100`（与 BODY/TAIL/EYE 单位一致），负空间孔用 mask 实现：

```svg
<mask id="eye"><rect width="110" height="100" fill="#fff"/>
  <circle cx="34" cy="47" r="3.8" fill="#000"/></mask>
<g mask="url(#eye)" fill="#EDF1F6">
  <ellipse cx="46" cy="50" rx="28" ry="16"/>
  <polygon points="69,42 106,23 98,50 106,77 69,58"/>
</g>
```

## 四、放回画布

- 横幅：左上角，高 56–58px，左边距与标题左边距对齐（同一根竖线），与标题顶端留 ≥40px。
- 表情图：**不要加**。加了会被判为水印，且破坏透明底。
- 头像／店铺：透明 PNG 直接叠，深底用浅色版。
- 安全距离：标记外接框四周留 ≥0.5 倍标记高度的空白，不与任何其他元素重叠。

## 五、常见错

- 把标记和文字排在一起 → 缩小即糊，失去车标属性。
- 标记用三色以上 → 不能压花、不能单色印刷。
- 负空间孔离边缘太近 → 缩小后孔与边缘粘连成缺口。
- 只出高分辨率 PNG 不出 SVG → 后续上物料（印刷、招牌、包装）没法放。
