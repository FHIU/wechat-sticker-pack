# 抠透明规范（四步法）

> 针对「纯白底生成的 Q 版贴纸」这类素材。目标：深色聊天底上看不出白边、白块、白雾。
> 实现见 `scripts/cutout.py`，本文是判定标准与排查手册。

## 一、为什么只抠「近白背景」不够

四个高频失败，全部发生在「看起来已经透明」之后：

| 现象 | 根因 | 对应步骤 |
|---|---|---|
| 链子周围一圈白块 | 白区被角色围成闭环，不与画布四边连通，被当成主体保留 | ② 闭环空洞 |
| 轮廓外一圈白线 | 原图自带 1–2px 白色贴纸描边，缩到 240 后更明显 | ③ 白描边剥离 |
| 边缘发白发雾 | 半透明像素的 RGB 是混白后的颜色，直接留 50% 透明度就是白雾 | ④ 颜色回填 |
| 边缘毛刺、碎点 | 抗锯齿产生孤立小连通块，缩放后更碎 | ④ 碎块清理 |

## 二、四步参数

### ① 清四边连通背景

- 候选：`亮度(最小通道) ≥ 226` 且 `饱和度(最大−最小) ≤ 30`
- 只清理**与画布四边连通**的连通域，绝不按亮度全局清理
- alpha 用渐变：`alpha = clip((232 − 亮度) / 18, 0, 1) × 255`

只清连通域的原因：白色方巾、眼白、银饰高光、镜片反光都是「近白但属于主体」，全局按亮度抠会在主体上打洞。

### ② 清闭环空洞

- 候选更严：`亮度 ≥ 236` 且 `饱和度 ≤ 14` 且 `面积 ≥ 120`（@1024 边长）
- 排除与四边连通的区域，剩下的内部近白块即空洞
- 再做一次亮度/饱和度均值复核（`lum ≥ 236`、`sat ≤ 14`）才打透

典型场景：耳下珠链与脸颊、肩膀围成的环；手臂与躯干之间的闭合缝隙。
判定红线：带深墨描边的银珠本身是主体，必须完整保留；只打透珠子之间的空隙。

### ③ 白描边剥离（两档）

以「距透明区的距离」划带，只压轮廓外侧：

```
0 – 2.5px 带：alpha ×= 1 − clip((亮度 − 194) / 46, 0, 1)      # 亮度 ≥240 直接清零
2.5 – 5px 带：alpha ×= 1 − 0.55 × clip((亮度 − 212) / 38, 0, 1)
```

不进入主体内部的原因：镜片高光、白方巾、银饰都落在主体内部较深处，5px 带已经足够覆盖描边宽度。

### ④ 颜色回填 + alpha 提纯

```python
# 用最近的不透明像素颜色填半透明边缘
core = (alpha >= 248)
_, lab = cv2.distanceTransformWithLabels(1 - core, cv2.DIST_L2, 5,
                                         labelType=cv2.DIST_LABEL_PIXEL)
ys, xs = np.where(core == 1)
filled = rgb[ys[lab - 1], xs[lab - 1]]

# alpha 提纯：保留 1px 抗锯齿，去掉大片半透明
alpha = clip((alpha - 45) / 150, 0, 1) * 255
alpha[alpha < 45] = 0
```

最后清掉面积 < 120（@1024）的孤立连通块，只保留最大主体。

## 三、验收指标（缺一不可）

| 指标 | 阈值 | 测法 |
|---|---|---|
| 边缘带浅色像素占比 | 亮度 ≥200 的像素 ≤ 2% | 距透明区 ≤2px 的环带 |
| 纯白像素 | 亮度 ≥230 的像素 = 0 | 同上 |
| 四角 | alpha = 0 | 四角取样 |
| 孤立碎块 | 只应有 1 个主体连通块（含文字层后为 2） | 8 邻域连通域 |
| 主体面积变化 | 相对上一版收缩 ≤ 8% | 仅外缘收缩可接受 |
| 视觉 | 深底、白底、64px 缩略三处都干净 | 人工看 |

主体不得缺肉：发梢、指节、链子、衣角若出现「刀切」或变细，说明阈值过激，减小带宽或提高亮度起点。

## 四、失败排查

| 现象 | 调整 |
|---|---|
| 头发外缘仍有灰白亮边 | 把 0–2.5px 带的亮度起点从 194 降到 185 |
| 头发被削薄、发梢变短 | 亮度起点提到 205，或带宽从 2.5px 收到 2px |
| 主体内部出现漏洞 | 检查是否误用了全局亮度清理；改回连通域 |
| 银饰/方巾被抠掉 | 闭环空洞的 `lum ≥ 236` 门槛过低，或面积门槛过低误伤 |
| GIF 在深底上仍有白圈 | 少了「颜色回填」这一步；GIF 必须先把边缘 RGB 换成实心色再二值化 alpha |

## 五、缩放与居中

- 缩放用 LANCZOS，输出 240×240；主体高建议 208（上下各留 16px）。
- 居中按**实际 alpha 外接框**对齐到 `(119.5, 119.5)`，不是按画布中心硬贴。
- 缩放后再做一次「边缘近白抑制 + 颜色回填 + alpha 提纯」，因为 LANCZOS 会重新引入半透明混白。
