# 提示词填空表（S2 交付物）

> **技能只提供骨架，内容由使用者填。**
> 本文件是空表与填写标准。技能在 S2 把这张表交给用户填，填完才进 S3 出母图。
> 不填 = 不出图。技能不得替用户编造形象、画风、姿势。

---

## 为什么必须由你填

同一套流程，换个角色、换个画风，提示词就完全不同。技能替你写，只会写出一个不属于你的角色——后面 16 张全部跑偏，返工比重写提示词贵得多。

技能负责的是：**哪些字段必须有、每个字段写多细、相邻两张怎么不撞、哪些词不能写**。这些是格式与规范，可以标准化；「他长什么样」不能。

---

## A 区｜不变项（全套装填一次，母图据此锁定）

填完这一区，母图就是它的视觉基准，后面每张都照抄，不再改。

| 字段 | 你填 | 填写标准 |
|---|---|---|
| 主角名 | | 2–6 字，后面命名清单要用 |
| 一句话形象 | | 年龄感 / 体型 / 发型 / 服装 / 配饰 / 气质，六个维度都点到 |
| 画风 | | 线条（粗细、是否描边）· 上色（扁平/厚涂/渐变）· 比例（几头身） |
| 配色 | | 主色 + 辅色 + **禁用色**（禁用色常被忽略，写上去能挡住一半跑偏） |
| 构图 | | 朝向（正面/微侧/侧）· 留白比例 · 脚底基线位置 |
| 禁止项 | | 默认六条见下，可加你自己的禁忌 |

**禁止项默认模板**（直接用，或按需加减）：

```
画面中不得出现文字、水印、logo、边框、地面投影、多个角色；
不得改变发型长度、服装款式、配饰数量；
不得使用渐变背景、噪点、油画质感。
```

**这一区最常见的错**：

| 反例 | 为什么不行 | 改成 |
|---|---|---|
| 「一个帅气的男生」 | 不可复现，16 张会长出 16 张脸 | 「25 岁上下，偏瘦，蓬松银灰短发带一撮挑染，黑色修身西装，整套银饰（耳扣、锁骨链、戒指），冷感」 |
| 「卡通风格」 | 等于没说 | 「Q 版约 3 头身，1.5px 深墨描边，扁平纯色上色，无渐变」 |
| 配色只写「深色系」 | 每张色温会飘 | 「主色 #14181D，辅色 #EDF1F6，点缀银灰 #9AA6B4；禁用暖色与高饱和」 |

## B 区｜逐张变量（N 行，一行动作一张）

只填两样：姿势、表情。A 区的内容每张照抄，不用重复写。

| 编号 | 名称 | 图上短句 | 本张姿势 | 本张表情 |
|---|---|---|---|---|
| 01 | | | | |
| 02 | | | | |
| 03 | | | | |
| … | | | | |

**填写标准**

- **姿势写到关节层面**：哪只手、抬到哪个高度、手指什么状态、身体朝向、重心在哪条腿。
- **表情写形状，不写情绪**：「嘴角单侧上扬 5°、眼睑下垂半遮瞳」比「嘲讽」可复现。
- 名称 ≤4 字最佳（≤8 字上限）；图上短句 ≤4 字，因为要当含义词用。
- 名称与短句可以不同：名称是专辑里的条目名，短句是画在图上给人看的。

**相邻两张不许撞**，这是整套最容易翻车的地方：

| 反例 | 问题 | 改法 |
|---|---|---|
| 01「抬手摊掌」、02「抬手摊掌」 | 同一姿势换文字，动态表情看起来是静止的 | 02 改成「双手抱胸，下巴微抬」 |
| 06「食指推眼镜」、13「食指点下巴」 | 都是手到脸，缩略图上几乎一样 | 13 改成「抱臂歪头」或「手插兜侧身」 |
| 12、14 都写「站直不动」 | 两张都没有动作信息 | 12 竖大拇指，14 单手扶额 |
| 全部都是上半身 | 缺变化，也浪费画布空间 | 至少 1/3 张要有明显手部或道具动作 |

**自检三问**（填完后过一遍）

1. 把 16 行姿势遮住名称单看，能两两区分吗？
2. 有没有两行只差一个手指？有就合并或改掉一行。
3. 情绪覆盖全了吗——怼人 / 摆烂 / 应答 / 告别，四类各占一些，不要 16 张全在生气。

## 填完之后

技能拿到这张表，只做三件事：

1. **校验**：必填项缺没缺、姿势有没有撞、字数超没超。不合格就退回让你补，不擅自补写。
2. **拼提示词**：母图 = A 区一段；第 N 张 = A 区 + B 区第 N 行。原文照抄，不改你的措辞。
3. **出图与收尾**：按 S3 起走，抠透明、叠字、合成 GIF、校验由脚本完成。

一份填好的实例见 `prompt-example.txt`（虚构柴犬角色，8 行；可对照结构，**内容不要照抄**）。
